Duplicate Tab Closer privacy policy

Effective October 8, 2026 · Version 1.0.0

Runs entirely in your browser. No accounts, analytics, ads, or data sent to us.

What the extension handles

The tabs permission lets the extension read the URLs and titles of open tabs in accessible windows of your current Chrome profile. It also uses tab IDs, window IDs, positions, and pinned, active, and discarded status to show a preview and close tabs you choose. Incognito use is disabled.

Use and retention

Tab information is processed locally in popup memory to identify and display duplicate tabs. It is not written to persistent storage, sent over the network, sold, shared, or used for advertising. The extension does not read page contents, forms, cookies, passwords, or browsing history. Closing the popup ends its processing and releases its tab information. Refresh scans tabs while the popup is open; it never closes tabs automatically.

Permissions and control

Only the tabs permission is requested. No website access permissions, account, backend, remote scripts, or telemetry are used. You control each close action, can disable auto-refresh, and can remove the extension at any time.

Limited Use

The extension's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for the visible duplicate-tab management feature.

External services and support

Chrome, the Chrome Web Store, and GitHub have their own privacy practices. Opening the repository, installing updates through Chrome, or voluntarily submitting an issue is separate from extension processing. Do not put private tab URLs, tokens, or titles in public issues. Support and source repository. External links are opened only by your explicit action.

Changes

Future changes will be documented with the source release and this policy. Version 1.0.0 has no data collection by the developer.
