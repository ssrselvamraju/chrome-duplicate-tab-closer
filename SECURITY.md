# Security

Version 1.0.x is the initial supported release line. To report a vulnerability, use GitHub's private vulnerability reporting feature on this repository when enabled. If that feature is unavailable, open an issue requesting a private reporting channel without including exploit details or private data. Do not include live tokens, browsing history, or personal URLs in public reports.

The extension does not collect logs or diagnostics automatically. Include only synthetic steps and redacted information. Maintainers should enable private vulnerability reporting before public release and maintain a private response channel.
